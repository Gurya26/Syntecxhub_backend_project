# User CRUD API Project

## Description
This project is a full-stack User Management system built using:
- Node.js
- Express.js
- MongoDB (Mongoose)
- HTML, CSS, JavaScript

## Features
- Add User
- View Users
- Update User
- Delete User
- Input Validation
